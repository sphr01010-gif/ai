# دستیار هوش مصنوعی شخصی تلگرام

بات خصوصی مبتنی بر Python برای گفت‌وگو، جست‌وجوی وب همراه منبع، تحلیل عکس و سند، یادآوری، خلاصه‌های زمان‌بندی‌شده، یادداشت‌های شخصی و تنظیم سبک پاسخ. **مدل هوش مصنوعی در این نسخه فقط از APMIX استفاده می‌کند.** برای بازیابی وب Tavily استفاده می‌شود و Telegram Bot API صرفاً پیام‌ها را منتقل می‌کند.

بات با polling اجرا می‌شود و به دامنه یا webhook نیاز ندارد. پردازش پیام‌ها در سطح برنامه به شناسهٔ عددی یک کاربر محدود است.

## امکانات

- گفت‌وگوی فارسی/چندزبانه با تاریخچهٔ قابل‌خاموش‌کردن در SQLite.
- **حافظهٔ شخصی با اجازهٔ صریح:** یادداشت فقط پس از انتخاب «ثبت یادداشت» ذخیره می‌شود؛ نمایش، حذف تکی و حذف همه با تأیید در دسترس است. استفاده از یادداشت‌ها در پاسخ‌ها جداگانه خاموش/روشن می‌شود.
- **تنظیمات شخصی:** زبان (خودکار/فارسی/English)، لحن (دوستانه/رسمی/خودمانی) و سبک پاسخ (معمولی، کوتاه، مشروح، آموزشی، ایده‌پردازی یا پژوهش).
- **جست‌وجوی وب با منابع:** پیوند منابع مستقیم نمایش داده می‌شود؛ دکمهٔ «مقایسهٔ منابع» جست‌وجوی عمیق‌تر را برای مقایسهٔ چند نتیجه اجرا می‌کند. تاریخ انتشار فقط وقتی سرویس جست‌وجو آن را برگرداند نمایش داده می‌شود.
- **یادآوری طبیعی و مطمئن:** عبارت‌های فارسی مانند «۳۰ دقیقه دیگر تماس با علی»، «فردا صبح تماس» یا «هر روز ساعت ۸ دارو» پذیرفته می‌شود. بات زمان تشخیص‌داده‌شده را نشان می‌دهد و **تا انتخاب «تأیید یادآوری» چیزی ذخیره نمی‌کند**. یادآوری‌ها قابل‌ویرایش، حذف و پس از ارسال قابل‌تعویق‌اند؛ تکرار روزانه و هفتگی نیز پشتیبانی می‌شود.
- **خلاصه‌های زمان‌بندی‌شده:** خلاصهٔ روزانه و هفتگی با انتخاب ساعت محلی؛ می‌توان موضوعات دلخواه را برای پیگیری اضافه یا حذف کرد. اگر Tavily فعال باشد، خلاصهٔ موضوع‌ها با لینک منبع تهیه می‌شود.
- **تحلیل فایل با پیگیری:** تصویر، PDF متنی/اسکن‌شده، DOCX، TXT، MD، CSV، JSON و فایل‌های متنی متداول بررسی می‌شوند. برای PDF اسکن‌شده، حداکثر سه صفحهٔ نخست به تصویر تبدیل و به مدل بینایی APMIX فرستاده می‌شود. با انتخاب دکمهٔ «بررسی عکس/سند»، آخرین فایل به‌طور خصوصی در SQLite نگه داشته می‌شود تا بتوانی درباره‌اش پرسش تکمیلی بپرسی؛ دکمهٔ «فراموش‌کردن فایل» آن را پاک می‌کند.
- **خروجی یادآوری‌ها به CSV** از منوی تنظیمات.
- **کیبورد ثابت Telegram** پایین کادر پیام؛ کارهای اصلی از دکمه‌ها انجام می‌شوند و بعد از انتخاب یک قابلیت، متن عادی می‌فرستی.
- **صوت عمداً غیرفعال است:** فقط وقتی برای APMIX مستند و قابل‌تأیید شود فعال خواهد شد؛ در این نسخه هیچ فایل صوتی به ارائه‌دهندهٔ هوش مصنوعی دیگری فرستاده نمی‌شود.

## استفاده از منو

با زدن **Start** کیبورد پایین صفحه ظاهر می‌شود. نمونهٔ استفاده:

1. «جست‌وجوی وب» یا «مقایسهٔ منابع» را انتخاب کن و پرسش را عادی بفرست.
2. «ثبت یادآوری» را انتخاب کن، عبارتی مثل «فردا ساعت ۹:۰۰ تماس با علی» بنویس، زمانِ نشان‌داده‌شده را بررسی کن و فقط در صورت درست‌بودن دکمهٔ تأیید را بزن.
3. «بررسی عکس/سند» را انتخاب کن و فایل را بفرست؛ پس از پاسخ می‌توانی پرسش دیگری دربارهٔ همان فایل بپرسی.
4. «حافظهٔ شخصی»، «تنظیمات» یا «خلاصه‌ها» را باز کن تا یادداشت‌ها، لحن و زبان، تاریخچه، خلاصه‌ها و موضوعات را مدیریت کنی.

نیازی نیست دستورهایی مثل `/search` یا `/remind` تایپ کنی. رنگ و اندازهٔ دقیق دکمه‌ها را خود Telegram و دستگاه تعیین می‌کند؛ برنامه فقط ترتیب ردیف‌ها و متن آن‌ها را می‌فرستد.

## ساخت کلید APMIX

1. به [apmix.ai](https://apmix.ai/) برو و از داشبورد **API keys** یک کلید بساز.
2. کلید واقعی را در چت یا مخزن GitHub قرار نده؛ آن را فقط در Railway Variables یا فایل محلی محافظت‌شدهٔ `.env` وارد کن.
3. مدل پیش‌فرض `claude-sonnet-4-6-free` است؛ دسترسی مدل‌ها و موجودی/سهمیه را در داشبورد APMIX بررسی کن. شناسهٔ دقیق مدل را می‌توانی از API فهرست مدل‌ها ببینی:

   ```bash
   curl https://api.apmix.ai/v1/models \
     -H "Authorization: Bearer apx_live_YOUR_KEY"
   ```

4. اگر مدل پیش‌فرض برای کلیدت فعال نیست، متغیر `APMIX_MODEL` را در Railway به شناسهٔ مجاز تغییر بده. ورودی تصویر نیز به پشتیبانی مدل انتخاب‌شده نیاز دارد.

اتصال Chat Completions از `https://api.apmix.ai/v1/chat/completions` استفاده می‌کند؛ مستندات را در [APMIX API Docs](https://apmix.ai/docs) ببین.

## متغیرهای محیطی

در Railway → Service → **Variables** این مقادیر را تنظیم کن:

- `TELEGRAM_BOT_TOKEN` — توکن ساخته‌شده با `@BotFather`.
- `TELEGRAM_ALLOWED_USER_ID` — شناسهٔ عددی حساب تلگرامی مجاز.
- `APMIX_API_KEY` — کلید داشبورد APMIX.
- `APMIX_MODEL` — شناسهٔ مدل مجاز؛ پیش‌فرض `claude-sonnet-4-6-free`.
- `TAVILY_API_KEY` — کلید Tavily برای جست‌وجوی وب و منابع. بدون آن گفت‌وگوی عادی و سایر قابلیت‌های APMIX فعال می‌مانند، اما وب‌گردی و نتایج زندهٔ موضوع‌ها در خلاصه‌ها غیرفعال است.
- `TIMEZONE` — منطقهٔ زمانی؛ پیش‌فرض `Asia/Tehran`.
- `BOT_DATA_DIR` — در Railway مقدار `/data`.

`.env.example` فقط قالب متغیرهاست و هیچ کلید واقعی ندارد. فایل `.env` در Git نادیده گرفته می‌شود.

## استقرار روی Railway از GitHub

1. در Railway یک Project بساز و **Deploy from GitHub Repo** را انتخاب کن؛ مخزن و شاخهٔ `main` را وصل کن.
2. این برنامه یک **worker** است؛ فرمان اجرا `python bot.py` است و در `Procfile` هم تعریف شده. پورت عمومی لازم نیست.
3. متغیرهای محیطی بالا را وارد کن.
4. یک Railway Volume به مسیر `/data` وصل کن و `BOT_DATA_DIR=/data` قرار بده. **بدون Volume ممکن است سابقه، یادداشت‌ها، فایل ذخیره‌شده و یادآوری‌ها با بازاستقرار از دست بروند.**
5. سرویس را Deploy کن. در Logs باید پیامی شبیه `Telegram bot connected as @...` دیده شود.
6. در تلگرام Start را بزن و جریان گفت‌وگو، جست‌وجو، تأیید یادآوری، ذخیره/فراموش‌کردن فایل و تنظیم خلاصه را آزمایش کن.

## اجرای محلی

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# مقدارهای محرمانه را فقط در .env محلی وارد کنید؛ این فایل در .gitignore است.
python bot.py
```

## حریم خصوصی و امنیت

- پیش از پردازش محتوا، شناسهٔ تلگرامی با `TELEGRAM_ALLOWED_USER_ID` مقایسه می‌شود؛ پیام‌های گروهی نادیده گرفته می‌شوند.
- یادداشت‌های شخصی فقط با انتخاب صریح کاربر ذخیره می‌شوند؛ استفاده از آن‌ها مستقل از ذخیرهٔ تاریخچه قابل‌خاموش‌کردن است.
- تاریخچهٔ متن، وضعیت‌های فعال، یادآوری‌ها، تنظیمات و فایلی که پس از انتخاب دکمهٔ بررسی فرستاده شده باشد در SQLite نگه داشته می‌شوند. حذف تاریخچه، یادداشت‌ها و فایل هرکدام جداگانه انجام می‌شود.
- درخواست‌های مدل، متن‌ها و تصاویر انتخاب‌شده به APMIX فرستاده می‌شوند؛ فقط عبارت‌های جست‌وجو و درخواست‌های موضوعی برای بازیابی وب به Tavily می‌روند. سیاست‌های نگه‌داری دادهٔ این سرویس‌ها را بررسی کن.
- کلیدهای واقعی را commit نکن. اگر کلیدی افشا شد، آن را در سرویس مربوط لغو و دوباره صادر کن.
