# دستیار هوش مصنوعی شخصی تلگرام

بات خصوصی مبتنی بر Python برای گفت‌وگوی فارسی/چندزبانه و جست‌وجوی وب. اتصال APMIX، Google Gemini و Groq (اختیاری) همراه با fallback خودکار پشتیبانی می‌شود؛ Tavily برای جست‌وجوی وب و Telegram Bot API برای انتقال پیام‌ها استفاده می‌شود.

بات با polling اجرا می‌شود و به دامنه یا webhook نیاز ندارد. پردازش پیام‌ها به شناسهٔ عددی یک کاربر و گفت‌وگوی خصوصی محدود است.

## منوی فعلی تلگرام

کیبورد پایین صفحه این گزینه‌ها را دارد:

- **گفت‌وگو:** متن دلخواهت را بفرست.
- **جست‌وجوی وب:** پرسشت را بفرست تا پاسخ همراه منبع بگیری.
- **انتخاب API:** برای چت APMIX، Gemini، Groq یا «خودکار» را انتخاب کن. انتخاب برای حساب تلگرامی تو ذخیره می‌شود؛ در انتخاب دستی، جایگزینی خودکار خاموش است مگر اینکه دکمهٔ «جایگزینی هنگام خطا» را روشن کنی.
- **ساخت تصویر:** یک توضیح کوتاه بفرست تا Cloudflare FLUX.1 [schnell] تصویر را تولید کند؛ این گزینه به Cloudflare Account ID و API Token نیاز دارد.

پاسخ‌ها برای خوانایی بهتر، عنوان‌ها، فهرست‌های تو‌در‌تو، نقل‌قول، متن پررنگ/کج/خط‌خورده، کد و پیوندهای امن را با قالب Telegram نمایش می‌دهند؛ قالب پاسخ هم برای صفحهٔ باریک موبایل به پاراگراف‌ها و فهرست‌های کوتاه تشویق می‌شود. متن HTML خام escape می‌شود تا محتوای معمولی به‌اشتباه به‌عنوان قالب اجرا نشود. هنگام فکرکردن، جست‌وجو، ساخت تصویر یا آماده‌سازی فایل، نشانگر «در حال نوشتن/ارسال» متناسب نمایش داده می‌شود.

## ساخت فایل در تلگرام

درخواست ساخت فایل را همراه با پسوند و توضیح محتوا بنویس؛ برای نمونه: «یک فایل `.py` بساز که چند عدد را جمع کند»، «یک PDF فارسی دربارهٔ برنامهٔ سفر بساز» یا «یک `.zip` شامل `main.py` و `README.md` بساز». ربات فایل را می‌سازد و به‌صورت سند در تلگرام می‌فرستد. ساخت PDF و ZIP داخل ربات انجام می‌شود و API جداگانه یا کلید تازه لازم ندارد؛ تولید محتوا با همان ارائه‌دهندهٔ انتخاب‌شدهٔ APMIX/Gemini/Groq انجام می‌شود.

کدهای `.py` فقط به‌عنوان فایل تحویل داده می‌شوند و ربات آن‌ها را اجرا نمی‌کند. مسیرهای داخل ZIP اعتبارسنجی می‌شوند و آرشیو حداکثر ۲۰ فایل متنی کوچک می‌پذیرد. برای تشخیص خودکار، در هر درخواست یک قالب اصلی را مشخص کن؛ اگر چند پسوند را نام ببری، ربات آن را به‌عنوان درخواست ساخت فایل تلقی نمی‌کند، مگر اینکه صریحاً ZIP حاوی آن‌ها بخواهی.

Gemini در خطاهای موقتی `408`، `429` و `5xx` حداکثر دو بار با مکث افزایشی و کوتاه دوباره تلاش می‌کند. خطاهای احراز هویت و درخواست‌های نامعتبر retry نمی‌شوند. در حالت دستی، fallback فقط با روشن‌کردن دکمهٔ جداگانه فعال می‌شود؛ حالت «خودکار» همچنان ترتیب `AI_PROVIDER_ORDER` را دنبال می‌کند.

## اتصال Groq

از [کنسول Groq](https://console.groq.com/keys) یک API key بساز و آن را فقط در Railway → Service → **Variables** با نام `GROQ_API_KEY` ثبت کن؛ کلید را در گفتگو یا GitHub قرار نده. مدل پیش‌فرض `GROQ_MODEL=openai/gpt-oss-20b` است. می‌توانی شناسهٔ مدل فعال دیگری را از [فهرست رسمی مدل‌های Groq](https://console.groq.com/docs/models) انتخاب کنی.

برای چت، در تلگرام «انتخاب API» و سپس «Groq» را بزن؛ یا حالت «خودکار» را انتخاب کن تا ربات طبق `AI_PROVIDER_ORDER` پیش برود. ترتیب پیش‌فرض `apmix,gemini,groq` است. اگر قبلاً در Railway مقدار `AI_PROVIDER_ORDER` را دستی تنظیم کرده‌ای، آن را به‌روز کن. پیاده‌سازی از endpoint سازگار با OpenAI در `https://api.groq.com/openai/v1/chat/completions` استفاده می‌کند. هزینه و محدودیت مصرف به حساب و طرح Groq بستگی دارد.

## ابزارهای دادهٔ خودکار

بات درخواست آب‌وهوا را از متن تشخیص می‌دهد و برای جست‌وجوی شهر و وضعیت فعلی/پیش‌بینی سه‌روزه از Open-Meteo استفاده می‌کند. مثال: «هوای شیراز چطوره؟». تبدیل ارز نیز بدون API key از Frankfurter استفاده می‌کند؛ مثال: «۱۰۰ دلار به یورو چند می‌شود؟». برای تبدیل، مبدأ و مقصد را صریح بنویس. نرخ‌های Frankfurter تاریخ‌دار و مرجع‌اند، نه نرخ لحظه‌ای خریدوفروش یا نرخ تضمینی بازار ایران. این endpoint عمومی برای نرخ/تجارت لحظه‌ای طراحی نشده است.

قابلیت‌های جدید به شکل registry در `bot.py` پیاده شده‌اند؛ ابزار تازه را با تابع `register_api_tool(name, matcher, handler)` می‌توان اضافه کرد، تا intent مناسب به handler همان API هدایت شود. ابزارهای داده‌ای پاسخ را از مقدار بازگشتی API می‌سازند و هنگام شکست سرویس مقدار حدسی نمی‌دهند. Open-Meteo و Frankfurter در نمونهٔ فعلی به کلید جداگانه نیاز ندارند؛ شرایط مجوز Open-Meteo را برای استفادهٔ تجاری جداگانه بررسی کن.

## ساخت تصویر با Cloudflare Workers AI

در داشبورد Cloudflare از بخش **Workers AI → Use REST API** یک Workers AI API Token بساز و **Account ID** را بردار. اگر به‌جای token آماده، token سفارشی می‌سازی، مستندات Cloudflare برای این API مجوزهای `Workers AI - Read` و `Workers AI - Edit` را ذکر می‌کند. هر دو مقدار را فقط در Railway → Service → Variables با نام‌های `CLOUDFLARE_ACCOUNT_ID` و `CLOUDFLARE_API_TOKEN` قرار بده؛ token را در GitHub یا گفتگو نفرست.

پس از deploy، روی دکمهٔ «ساخت تصویر» بزن و prompt را در پیام بعدی بفرست؛ یا مستقیم بنویس «یک تصویر از یک گربهٔ فضانورد بساز» / `Generate an image of a space cat`. ربات از مدل `@cf/black-forest-labs/flux-1-schnell` و مقدار `steps=4` استفاده می‌کند و خروجی را به‌صورت عکس تلگرام می‌فرستد. prompt حداکثر ۲۰۴۸ نویسه است. ممکن است اجرای Workers AI طبق سهمیه/طرح حساب Cloudflare هزینه یا محدودیت مصرف داشته باشد؛ جزئیات را پیش از استفاده بررسی کن.

## کیفیت پاسخ‌های جست‌وجو

برای نتیجه‌های وب، بات منبع‌ها و تاریخ انتشار موجود را همراه ارجاع نگه می‌دارد و پاسخ مدل را به «اطلاعات منبع‌شده» و «تحلیل» تفکیک می‌کند. اگر تاریخ انتشار منبع در دسترس نباشد، مدل باید آن را ناموجود بداند، نه حدس بزند.

جست‌وجوی خودکار فقط با درخواست روشن، مانند «در وب جست‌وجو کن» یا `search the web` فعال می‌شود. پرسش‌هایی که فقط واژه‌هایی مانند «امروز»، «آخرین»، «قیمت» یا «هوا» دارند، به‌تنهایی جست‌وجو را فعال نمی‌کنند. برای جست‌وجوی دستی، دکمهٔ «جست‌وجوی وب» را بزن.

برای خوانایی در تلگرام، خلاصهٔ وب کوتاه نگه داشته می‌شود، فهرست منبع تکراری حذف شده و URLهای بلند به پیوندهای کوتاه‌شده با دامنهٔ قابل‌مشاهده تبدیل می‌شوند.

## پیدا کردن و فرستادن عکس از اینترنت

برای نمونه بنویس: «عکس یک اسب از اینترنت پیدا کن و دانلود کن و توی چت بفرست». بات نتیجه‌های Wikimedia Commons را بر اساس ارتباط مرتب می‌کند، فایل‌های متحرک را کنار می‌گذارد، عکس را دریافت و در تلگرام ارسال می‌کند و عنوان، خالق (اگر موجود باشد)، مجوز و صفحهٔ منبع را در کپشن می‌آورد. اگر Railway دریافت مستقیم عکس را مسدود کند، لینک امن تصویر را به Telegram می‌دهد تا آن را دریافت و ارسال کند. این قابلیت با API عمومی Commons کار می‌کند و کلید جداگانه نمی‌خواهد. این مسیر از دکمه یا درخواست «ساخت تصویر» با Cloudflare Flux جداست.

گزینه‌های قبلی از منوی فعال حذف شده‌اند و حالت‌های نیمه‌تمام آن‌ها پس از دریافت پیام پاک می‌شوند. ارسال‌های زمان‌بندی‌شدهٔ یادآوری و خلاصه غیرفعال‌اند. داده‌های قدیمی داخل SQLite عمداً پاک نشده‌اند.

## ساخت کلید Google Gemini

از [Google AI Studio API keys](https://aistudio.google.com/api-keys) یک کلید Gemini بساز و مقدارش را فقط در Railway Variables با نام `GEMINI_API_KEY` ثبت کن؛ کلید را در GitHub یا گفت‌وگوها قرار نده. مدل پیش‌فرض `gemini-3.8-flash` است و می‌توانی آن را با `GEMINI_MODEL` تغییر دهی. کد از REST `generateContent` رسمی Gemini استفاده می‌کند.

## ساخت کلید APMIX

1. به [apmix.ai](https://apmix.ai/) برو و از داشبورد **API keys** یک کلید بساز.
2. کلید واقعی را در چت یا مخزن GitHub قرار نده؛ آن را فقط در Railway Variables یا فایل محلی محافظت‌شدهٔ `.env` وارد کن.
3. مدل پیش‌فرض `claude-sonnet-4-6-free` است؛ دسترسی مدل‌ها و موجودی/سهمیه را در داشبورد APMIX بررسی کن. شناسهٔ دقیق مدل را می‌توانی از API فهرست مدل‌ها ببینی:

   ```bash
   curl https://api.apmix.ai/v1/models \
     -H "Authorization: Bearer apx_live_YOUR_KEY"
   ```

4. اگر مدل پیش‌فرض برای کلیدت فعال نیست، متغیر `APMIX_MODEL` را در Railway به شناسهٔ مجاز تغییر بده. ورودی تصویر نیز به پشتیبانی مدل انتخاب‌شده نیاز دارد.

اتصال Chat Completions از `https://api.apmix.ai/v1/chat/completions` استفاده می‌کند؛ مستندات را در [APMIX API Docs](https://apmix.ai/docs) ببین.

## متغیرهای محیطی

در Railway → Service → **Variables** این مقادیر را تنظیم کن:

- `TELEGRAM_BOT_TOKEN` — توکن ساخته‌شده با `@BotFather`.
- `TELEGRAM_ALLOWED_USER_ID` — شناسهٔ عددی حساب تلگرامی مجاز.
- `APMIX_API_KEY` — کلید داشبورد APMIX.
- `APMIX_MODEL` — شناسهٔ مدل مجاز APMIX؛ پیش‌فرض `claude-sonnet-4-6-free`.
- `GEMINI_API_KEY` — کلید Google AI Studio؛ فقط در Railway Variables وارد شود.
- `GEMINI_MODEL` — شناسهٔ مدل Gemini؛ پیش‌فرض `gemini-3.8-flash`.
- `GROQ_API_KEY` — کلید API ساخته‌شده در کنسول Groq؛ فقط در Railway Variables وارد شود.
- `GROQ_MODEL` — شناسهٔ مدل Groq؛ پیش‌فرض `openai/gpt-oss-20b`.
- `AI_PROVIDER_ORDER` — ترتیب تلاش و fallback در حالت خودکار؛ پیش‌فرض `apmix,gemini,groq`، برای اولویت‌دادن به Groq مقدار `groq,apmix,gemini` بگذار. در حالت انتخاب دستی fallback را از دکمهٔ «انتخاب API» کنترل کن.
- `TAVILY_API_KEY` — کلید Tavily برای جست‌وجوی وب و منابع. برای فعال‌سازی، کلید را از داشبورد Tavily بساز و با همین نام دقیق در Railway → Service → **Variables** اضافه کن؛ سپس سرویس را redeploy کن. تا آن زمان گفت‌وگوی عادی فعال می‌ماند، اما جست‌وجوی وب اجرا نمی‌شود. کلید را در چت یا GitHub نفرست.
- `CLOUDFLARE_ACCOUNT_ID` و `CLOUDFLARE_API_TOKEN` — اختیاری؛ برای ساخت تصویر با Cloudflare Workers AI. این token جدا از کلیدهای APMIX و Gemini است.
- `TIMEZONE` — منطقهٔ زمانی؛ پیش‌فرض `Asia/Tehran`.
- `BOT_DATA_DIR` — در Railway مقدار `/data`.

`.env.example` فقط قالب متغیرهاست و هیچ کلید واقعی ندارد. فایل `.env` در Git نادیده گرفته می‌شود.

## استقرار روی Railway از GitHub

1. در Railway یک Project بساز و **Deploy from GitHub Repo** را انتخاب کن؛ مخزن و شاخهٔ `main` را وصل کن.
2. این برنامه یک **worker** است؛ فرمان اجرا `python bot.py` است و در `Procfile` هم تعریف شده. پورت عمومی لازم نیست.
3. متغیرهای محیطی بالا را وارد کن.
4. یک Railway Volume به مسیر `/data` وصل کن و `BOT_DATA_DIR=/data` قرار بده. **بدون Volume ممکن است سابقهٔ گفت‌وگو و داده‌های قدیمی SQLite با بازاستقرار از دست بروند.**
5. سرویس را Deploy کن. در Logs باید پیامی شبیه `Telegram bot connected as @...` دیده شود.
6. در تلگرام Start را بزن و گفت‌وگو و جست‌وجوی وب را آزمایش کن.

## اجرای محلی

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# مقدارهای محرمانه را فقط در .env محلی وارد کنید؛ این فایل در .gitignore است.
python bot.py
```

## حریم خصوصی و امنیت

- پیش از پردازش محتوا، شناسهٔ تلگرامی با `TELEGRAM_ALLOWED_USER_ID` مقایسه می‌شود؛ پیام‌های گروهی نادیده گرفته می‌شوند.
- تاریخچهٔ گفت‌وگو در SQLite نگه داشته می‌شود. داده‌های قدیمیِ قابلیت‌های حذف‌شده پاک نشده‌اند؛ برای حذف کامل آن‌ها باید دادهٔ SQLite مربوط به سرویس را جداگانه مدیریت کنی.
- درخواست‌های مدل، متن‌ها و تصاویر انتخاب‌شده به ارائه‌دهنده‌ای فرستاده می‌شوند که در `AI_PROVIDER_ORDER` موفق شود؛ فقط عبارت‌های جست‌وجو و درخواست‌های موضوعی برای بازیابی وب به Tavily می‌روند. سیاست‌های نگه‌داری دادهٔ این سرویس‌ها را بررسی کن.
- کلیدهای واقعی را commit نکن. اگر کلیدی افشا شد، آن را در سرویس مربوط لغو و دوباره صادر کن.
