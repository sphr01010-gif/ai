# دستیار هوش مصنوعی شخصی تلگرام

بات خصوصی مبتنی بر Python برای گفت‌وگوی فارسی/چندزبانه، جست‌وجوی وب با منبع، دریافت تصویر، خلاصه‌سازی سند و یادآوری زمان‌دار. **ارائه‌دهندهٔ مدل هوش مصنوعی در این نسخه فقط APMIX است.** برای دریافت/ارسال پیام، Telegram Bot API لازم است؛ برای جست‌وجوی وب نیز Tavily جداگانه استفاده می‌شود.

بات با polling کار می‌کند و نیازی به دامنه یا webhook ندارد. دسترسی در سطح برنامه به شناسهٔ عددی یک کاربر محدود است.

## امکانات

- گفت‌وگوی متنی با APMIX و نگه‌داری تاریخچهٔ کوتاه در SQLite.
- دریافت تصویر به قالب OpenAI-compatible برای مدل انتخاب‌شده ارسال می‌شود؛ پشتیبانی تصویر را در صفحهٔ مدل/حساب APMIX بررسی و با یک تصویر آزمایش کن.
- جست‌وجوی وب از طریق Tavily و خلاصه‌سازی نتیجه‌ها با APMIX، همراه پیوند منابع؛ با انتخاب دکمهٔ جست‌وجو و فرستادن پرسش انجام می‌شود.
- استخراج متن از PDF، DOCX، TXT، MD، CSV، JSON و فایل‌های متنی متداول.
- یادآوری پایدار در SQLite؛ منطقهٔ زمانی پیش‌فرض `Asia/Tehran` است.
- منوی inline برای گفت‌وگوی آزاد، جست‌وجو، ثبت/مشاهده/حذف یادآوری، بررسی عکس/سند، پاک‌کردن حافظه با تأیید و راهنما؛ بعد از انتخاب جست‌وجو یا یادآوری فقط متن/زمان را می‌فرستی، بدون دستور اسلش‌دار. callbackها فقط برای کاربر مجاز پردازش می‌شوند.
- پیام صوتی فعلاً پردازش نمی‌شود؛ در این نسخه مسیر صوتی با APMIX آزمایش نشده و هیچ ارائه‌دهندهٔ هوش مصنوعی دیگری فراخوانی نمی‌شود.

## استفاده از منوی تلگرام

با زدن دکمهٔ **Start** در صفحهٔ بات، منوی اصلی ظاهر می‌شود. برای گفت‌وگو، دکمهٔ گفت‌وگو را بزن و متن را عادی بفرست. برای جست‌وجو، اول دکمهٔ جست‌وجوی وب را بزن و بعد پرسش را بفرست. دکمهٔ بررسی عکس/سند هم دریافت فایل را راهنمایی می‌کند. برای ثبت یادآوری دکمهٔ ثبت یادآوری را بزن و زمان و متن را در یکی از این قالب‌ها بفرست:

- `30m تماس با علی` برای ۳۰ دقیقهٔ دیگر؛ واحدها `s`، `m`، `h` و `d` هستند.
- `2026-10-11 14:30 تماس با علی` برای تاریخ و ساعت مشخص به وقت تهران.

از دکمهٔ «یادآوری‌های من» می‌توان یادآوری‌های در انتظار را دید و هرکدام را جداگانه حذف کرد. گزینهٔ پاک‌کردن حافظه پیش از حذف تاریخچه تأیید می‌گیرد. پس از هر پاسخ، منوی اصلی دوباره در دسترس است. برای این کارها نیازی به نوشتن دستورهایی با `/` نیست.

## ساخت حساب و کلید APMIX

1. در [apmix.ai](https://apmix.ai/) روی **Get started** بزن و حساب بساز.
2. از داشبورد، **API keys** را باز کن و کلید بساز. کلیدها معمولاً با `apx_live_` شروع می‌شوند؛ مقدار واقعی را در چت یا مخزن GitHub قرار نده.
3. طبق صفحهٔ قیمت رسمی APMIX، حساب جدید یک‌بار ۳ میلیون توکن رایگان برای مدل رایگان `claude-sonnet-4-6-free` می‌گیرد، بدون کارت و بدون تاریخ انقضا. سهمیه‌ها و شرایط ممکن است تغییر کنند؛ مقدار فعلی را در حساب و [صفحهٔ قیمت](https://apmix.ai/pricing) بررسی کن.
4. برای دیدن مدل‌هایی که کلیدت اجازهٔ استفاده از آن‌ها را دارد، از این درخواست استفاده کن؛ جای‌نگهدار را با کلید خودت عوض کن و کلید را در چت یا GitHub نفرست:

   ```bash
   curl https://api.apmix.ai/v1/models \
     -H "Authorization: Bearer apx_live_YOUR_KEY"
   ```

   نام مدل پیش‌فرض برنامه `claude-sonnet-4-6-free` است. اگر فهرست `/v1/models` برای حسابت شناسهٔ دیگری نشان داد، مقدار `APMIX_MODEL` را دقیقاً به همان شناسه تغییر بده.

APMIX برای Chat Completions از آدرس `https://api.apmix.ai/v1/chat/completions` و احراز هویت `Authorization: Bearer ...` استفاده می‌کند. جزئیات را در [مستند رسمی API](https://apmix.ai/docs) ببین.

## متغیرهای محیطی

در Railway → Service → Variables این مقادیر را تنظیم کن:

- `TELEGRAM_BOT_TOKEN` — توکن `@BotFather`.
- `TELEGRAM_ALLOWED_USER_ID` — شناسهٔ عددی حساب تلگرامی مجاز.
- `APMIX_API_KEY` — کلید ساخته‌شده در داشبورد APMIX.
- `APMIX_MODEL` — شناسهٔ مدل مجاز برای کلید؛ پیش‌فرض `claude-sonnet-4-6-free`.
- `TAVILY_API_KEY` — کلید Tavily برای جست‌وجوی وب؛ بدون آن، گفت‌وگوی معمولی فعال می‌ماند اما جست‌وجو غیرفعال است.
- `TIMEZONE` — پیش‌فرض `Asia/Tehran`.
- `BOT_DATA_DIR` — در Railway مقدار `/data`.

`.env.example` فقط نام متغیرها و مقدارهای غیرمحرمانه را دارد. از آن کپی بگیر و کلید واقعی را فقط در Railway Variables یا `.env` محلیِ محافظت‌شده وارد کن؛ `.env` در Git نادیده گرفته می‌شود.

## استقرار روی Railway از GitHub

1. در Railway یک Project بساز و **Deploy from GitHub Repo** را انتخاب کن؛ مخزن و شاخهٔ `main` را وصل کن.
2. این پروژه یک **worker service** است؛ دستور اجرا `python bot.py` است و در `Procfile` نیز تعریف شده. دامنه و پورت عمومی لازم نیست.
3. متغیرهای بالا را در Variables وارد کن و تغییرات را deploy کن.
4. برای نگه‌داری تاریخچه و یادآوری‌ها بین deployها، یک Volume به مسیر `/data` وصل کن و `BOT_DATA_DIR=/data` بگذار.
5. در Logs دنبال پیامی مانند `Telegram bot connected as @...` بگرد. در صورت خطای 401 کلید را بررسی کن؛ برای خطای مدل یا سهمیه، خروجی `GET /v1/models` و بخش حساب/سهمیهٔ APMIX را بررسی کن.
6. در تلگرام دکمهٔ **Start** را بزن، سپس جست‌وجو، ثبت یادآوری و مدیریت یادآوری‌ها را از منوی inline آزمایش کن.

## اجرای محلی برای توسعه

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# مقادیر واقعی را فقط در .env محلی وارد کنید؛ این فایل در .gitignore است.
python bot.py
```

## حریم خصوصی و امنیت

- پیش از پردازش محتوا، شناسهٔ تلگرامی با `TELEGRAM_ALLOWED_USER_ID` مقایسه می‌شود؛ پیام‌های گروهی نادیده گرفته می‌شوند.
- تاریخچهٔ متنی اخیر، وضعیت مرحلهٔ انتخاب‌شده و یادآوری‌ها در SQLite ذخیره می‌شوند. گزینهٔ پاک‌کردن حافظه در منو پس از تأیید، تاریخچهٔ گفت‌وگو را پاک می‌کند؛ یادآوری‌ها جداگانه باقی می‌مانند.
- متن‌ها و تصویرهایی که برای پاسخ هوش مصنوعی پردازش می‌شوند به APMIX فرستاده می‌شوند؛ عبارت‌های جست‌وجو برای بازیابی وب به Tavily می‌روند. سیاست‌های نگه‌داری دادهٔ این سرویس‌ها را بررسی کن.
- اگر کلیدی افشا شد، آن را فوراً در سرویس مربوط لغو و دوباره صادر کن. کلیدهای واقعی را commit نکن.
